# مستندات API فروشگاه

مستندات تعاملی API با Swagger UI و استاندارد OpenAPI 3.0 ارائه می‌شود.

## اجرا

بعد از دریافت شاخه:

```bash
pnpm install
pnpm dev
```

سپس آدرس‌های زیر در دسترس هستند:

- Swagger UI: `http://localhost:3002/api-docs` (یا پورتی که در متغیر `PORT` تنظیم شده)
- فایل OpenAPI: `http://localhost:3002/openapi.json`
- Health check: `http://localhost:3002/health`

## احراز هویت در Swagger

سیستم احراز هویت پروژه از نشست با Cookie به نام `shop_session` و همچنین `Authorization: Bearer <token>` پشتیبانی می‌کند.

برای تست با Cookie، ابتدا endpoint ورود مشتری یا مدیر را از Swagger اجرا کنید. پاسخ موفق، Cookie نشست را تنظیم می‌کند و مرورگر آن را برای درخواست‌های بعدی به همان سرور ارسال می‌کند.

برای تست با Bearer، در دکمه **Authorize** گزینه Bearer را انتخاب و توکن نشست را وارد کنید.

## ساختار مستندات

تعریف OpenAPI در فایل `src/docs/openapi.ts` قرار دارد. مسیرها بر اساس Routeهای ثبت‌شده در ماژول‌ها وارد شده‌اند و سطح دسترسی عمومی، مشتری و مدیر مشخص شده است.

> نکته: توضیحات و مسیرها از Routeهای فعلی استخراج شده‌اند. Schemaهای دقیق ورودی و خروجی همه Controllerها هنوز به‌صورت کامل تعریف نشده‌اند؛ برای جلوگیری از نمایش قرارداد ساختگی، پاسخ‌ها فعلاً با ساختار عمومی نمایش داده می‌شوند. هنگام توسعه هر ماژول، فیلدهای واقعی request/response را به تعریف OpenAPI همان endpoint اضافه کنید.

## به‌روزرسانی

هر زمان Route جدیدی اضافه یا حذف شد، آرایه `routes` در `src/docs/openapi.ts` را نیز به‌روزرسانی کنید.
